
# Color Palette Extractor 🎨

A web-based Color Palette Extractor that allows users to upload images and automatically extract their dominant colors.

## Project Description

Color Palette Extractor is a responsive web application designed for students, designers, and creative individuals. It helps users identify the main colors of an image and generate color palettes for posters, artworks, and other design projects.

## Features

- Upload JPG and PNG images
- Drag-and-drop image uploading
- Image preview
- Extract 1 to 10 dominant colors
- Auto Extraction for multiple shade groups
- Display HEX color codes
- Display RGB color values
- Show approximate color percentages
- Copy HEX and RGB values
- Download extracted palettes as PNG images
- Reset and upload another image
- Responsive pink-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API
- GitHub Pages

## How to Use

1. Open the Color Palette Extractor website.
2. Upload a JPG or PNG image.
3. Select the desired number of colors or Auto Extraction.
4. Click "Extract colors".
5. View the extracted color palette.
6. Copy HEX or RGB codes as needed.
7. Click "Download palette PNG" to save the result.

## Deployment

This version is designed for GitHub Pages.

The color extraction process runs directly in the user's browser using JavaScript. No Python or Flask server is required.

To deploy, publish the main branch from the root directory using GitHub Pages.
